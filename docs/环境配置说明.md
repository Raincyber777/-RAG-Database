# 环境配置说明

本文档说明「智学纪要」的完整环境搭建流程，含依赖清单与环境变量说明，对应大赛「环境配置」提交要求。变量名与代码一一对应，模板见仓库根目录 [.env.example](../.env.example)。

---

## 一、依赖清单

### 1.1 系统级依赖

| 依赖 | 版本要求 | 用途 | 获取方式 |
|------|----------|------|----------|
| Python | 3.11+（开发环境 3.11/3.12） | 服务端运行时 | 官网 / 包管理器 |
| PostgreSQL | 17（16+ 均可） | 业务数据：账号、纪要、片段、问答、题库、审计 | 官网 / Docker |
| Node.js | ≥ 18 | 用户端 / 管理端前端构建 | 官网 |
| ffmpeg | 系统可用即可 | 视频材料浏览器端抽帧（ffmpeg.wasm 不需要服务端安装，服务端仅处理音频轨道） | 官网 |

> 说明：本系统**未使用独立向量数据库与 Redis**。片段向量（1024 维）存于 PostgreSQL 表字段中，检索召回在服务层用 numpy 余弦相似度完成；纪要生成流水线为独立 note_worker 进程（数据库状态机 + 串行队列），不依赖外部队列中间件。

### 1.2 服务端依赖

见 [requirements.txt](../requirements.txt)（根目录透传 mysite/requirements.txt + requirements-agent.txt）：

- Web 框架：Django 5.2 + Django REST Framework 3.17 + djangorestframework-simplejwt（JWT 鉴权）+ django-cors-headers
- 数据库驱动：psycopg2-binary
- AI / 网络：requests（DashScope HTTP 调用）、阿里云 OSS SDK（oss2）、阿里云短信 SDK（alibabacloud_dysmsapi20170525）
- 解析：pillow / pymupdf / python-docx / python-pptx / openpyxl（文档与表格解析）
- 计算：numpy（向量余弦检索）
- 生产 WSGI：gunicorn
- 配置加载：python-dotenv（本地 .env）

### 1.3 前端依赖

- 用户端（RAG-AI-system）：Vue 3 + TypeScript + Vite + Pinia + Vue Router + Element Plus + ECharts + JSZip
- 管理端（RAG-admin）：Vue 3 + TypeScript + Vite + Pinia + Vue Router + ECharts

## 二、环境变量

模板见仓库根目录 `.env.example`，共 8 组：

| 分组 | 关键变量 | 说明 |
|------|----------|------|
| Django 基础 | `DJANGO_DEBUG`、`RAG_DJANGO_SECRET_KEY`、`RAG_ALLOWED_HOSTS`、`RAG_CSRF_ORIGINS` | 生产必须 `DJANGO_DEBUG=False` 并注入正式密钥 |
| 数据库 | `RAG_DB_NAME/USER/PASSWORD/HOST/PORT` | PostgreSQL 连接 |
| AI 服务 | `DASHSCOPE_API_KEY` 及 `DASHSCOPE_*_URL` | 阿里云百炼：语音转写 / 图像理解 / 语言模型 / 向量统一入口 |
| 联网检索 | `TAVILY_API_KEY` | 留空即关闭联网补充 |
| Agent 运行时 | `AGENT_ENABLED`、`AGENT_CHAT_MODEL`、`AGENT_FAST_MODEL`、`AGENT_ASR_MODEL`、`AGENT_VISION_MODEL`、`AGENT_EMBEDDING_MODEL/DIMENSIONS`、`AGENT_ENABLE_SEARCH` 等 | 默认值即可跑通（qwen-plus / qwen-flash / paraformer-v2 / qwen3-vl-plus / text-embedding-v4） |
| 媒体存储 | `RAG_MEDIA_STORAGE`（local/oss）、`OSS_*` | 课堂原始材料与产物存储；oss 模式提供签名 URL |
| 邮件 | `RAG_EMAIL_HOST/PORT/SSL/USER/PASSWORD/FROM` | 注册与换绑验证码（SMTP） |
| 短信（可选） | `RAG_SMS_*` | 阿里云 Dysmsapi 短信验证码通道 |

### 安全要求（大赛明文规定）

1. **任何真实 API 密钥不得出现在公开仓库中**，一律通过环境变量注入；
2. `.env`、`local_settings.py` 必须写入 `.gitignore`；仓库仅保留 `.env.example`（键名 + 占位/默认值）；
3. 生产环境密钥通过部署环境（如服务器 `/etc/rag-backend.env`，权限 600）下发，不落仓库；
4. 若历史提交中曾误提交密钥，须**立即作废轮换**该密钥，而非仅删除文件。

## 三、部署步骤

### 3.1 本地开发

1. 安装依赖：

   ```bash
   pip install -r requirements.txt
   ```

2. PostgreSQL 中创建数据库：

   ```sql
   CREATE DATABASE rag_db ENCODING 'UTF8';
   ```

3. 复制 `.env.example` 为 `.env`，填入本机数据库口令与 `DASHSCOPE_API_KEY`（其余默认值即可跑通）；

4. 迁移与演示数据：

   ```bash
   cd mysite
   python manage.py migrate
   python manage.py seed_demo        # 两端演示账号 + 示例纪要/问答/题库/反馈/FAQ
   ```

5. 启动（两个进程）：

   ```bash
   python manage.py runserver        # API：http://127.0.0.1:8080
   python manage.py note_worker      # 纪要生成流水线（串行队列，支持取消）
   ```

6. 前端（另开终端，两个仓库各自执行）：

   ```bash
   npm install
   npm run dev                       # 用户端 :5173 / 管理端 :5174
   ```

### 3.2 生产部署（阿里云 ECS + Nginx + CI）

1. 服务器安装 Python 3.11+、PostgreSQL 17、Nginx；数据库建库；
2. `/etc/rag-backend.env` 写入生产环境变量（`DJANGO_DEBUG=False`、正式 `RAG_DJANGO_SECRET_KEY`、数据库口令、各服务密钥、`RAG_MEDIA_STORAGE=oss`）；
3. 推送触发 GitHub Actions：三仓库各自 CI 自动构建用户端 / 管理端静态资源（vue-tsc 类型检查通过后才部署）并发布到 Nginx 站点目录；后端 CI 自动 migrate 并重启 gunicorn 与 note_worker（systemd 服务）；
4. Nginx 端口规划：用户端 :8082、管理端 :8081、API :8080（反代 gunicorn）。

## 四、常见问题

| 现象 | 排查方向 |
|------|----------|
| 上传后一直"排队中" | note_worker 未启动（`python manage.py note_worker`）；或服务端日志中该任务 `last_phase` 报错 |
| 转写失败可重试但反复失败 | `DASHSCOPE_API_KEY` 失效或额度耗尽；语音通道需带 `X-DashScope-Async` 头提交文件转写 |
| 问答不展示来源卡片 | 引用强制校验未通过，属预期安全行为；仅真实标注的片段会作为引用展示 |
| 材料外问题直接拒答 | 预期行为：三档检索阈值（强相关作答 / 弱相关追问 / 无依据拒答）+ 引用校验 |
| 生成中点击"停止生成"无效 | 仅取消还在排队、未开始生成的任务，正在流式生成的当前份会完成当前步骤后中断 |
| 前端登录 403 / 跨域失败 | `RAG_CSRF_ORIGINS` 未包含前端地址，或 `RAG_ALLOWED_HOSTS` 未含访问域名 |
| 邮箱收不到验证码 | `RAG_EMAIL_*` 配置错误；QQ 邮箱需使用 SMTP 授权码而非登录密码 |
