# 智学纪要 Agent 设计

根据《智学纪要 · 提示词汇总》（2026-10-19）完善现有 LangChain Agent，并按后续要求扩展流式问答和材料入库链路。现已包括 ASR、文件抽取/OCR、向量化、SQLite 知识库及可注入认证的 FastAPI SSE 适配器；文件上传与身份认证仍由宿主负责。

## 结构与职责

- `prompts.py`：调度提示词与问答三档、外部审核、纪要 map/reduce、出题、视觉、追问提示词。
- `schemas.py`：上下文、检索片段、外部证据及结构化输出契约。
- `backend.py`：后端协议。按上下文提供授权材料、检索片段、用户资料；调用方负责认证，工具不接受用户/租户 ID。
- `gateway.py`：百炼兼容接口 JSON/视觉生成、原生搜索。超时和格式失败返回空结果，不重试；客户端可注入便于离线测试。
- `services.py`：依据分档和输出校验；保证引用只映射真实证据、时间戳取自材料、不强凑题数。模型失败用原文摘录或空结构降级。
- `tools.py`：把业务服务、用户资料、偏好读写暴露为 Agent 工具。业务结果直接返回，避免调度模型二次改写已校验答案。
- `runtime.py`：惰性构建 Agent，真实模型调用自动计数，绑定用户作用域会话 ID；内存默认、PostgreSQL 检查点可选且显式初始化。
- `extraction.py`、`media.py`：文档/PDF/PPT/图片抽取，paraformer-v2 异步录音转写，text-embedding-v4 向量接口。
- `knowledge.py`、`ingestion.py`：带身份约束的材料登记、原始片段与检索分块持久化、事务内替换、余弦召回。
- `transport.py`：SSE 编码及认证依赖注入；正文增量为临时结果，最终 replace/done 作为权威版本。

## 行为约束

材料和工具返回内容是数据，不执行其中的指令。优先知识库；可使用内置 SQLite 知识库或注入已有后端，问答按原始余弦相似度 0.42/0.22 分档、Top-K=4。无可靠证据直接固定回复，不调用回答模型。外部结果必须来自原生搜索返回的 URL 清单，low 不用于回答。JSON 严格验证，额外字段拒绝。少量材料允许不足推荐条数，忠实性优先。偏好默认只在进程内保存，可注入持久化 store。

本实现不声称校验能证明模型每个自然语言结论正确；代码校验覆盖格式、引用存在性和来源约束，内容忠实性仍需真实数据评测。

## 验证

使用标准库 unittest、真实 LangGraph 图、临时 SQLite 索引、真实文档格式及可控模型/HTTP 测试替身，覆盖分档、引用、流式、转写、抽取、入库、租户隔离和故障降级。测试不访问部署数据库或真实付费模型。
