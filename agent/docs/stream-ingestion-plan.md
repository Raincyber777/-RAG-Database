# 流式问答与材料入库（2026-10-19）

用户已要求将 Agent 改为流式，并补齐 ASR、文档/PDF/PPT 抽取、向量化链路。

## 接口与行为

1. `StudyAgent.stream()` 经过相同的 LangGraph 工具路由与会话隔离，输出 `status/delta/replace/sources/followups/done`。`delta` 是临时文本，`replace` 为校验后权威正文，客户端必须替换，不能仅追加。错误也以替换与终结事件结束。原 `invoke` 保持兼容。提供 SSE 序列化与可注入认证的 FastAPI router。
2. 抽取器支持 UTF-8 TXT/Markdown、DOCX 段落和表格、PDF 逐页文字及空白文字层 OCR、PPTX 文本/表格/图片 OCR。旧 DOC/PPT 经已安装 LibreOffice 转换；未安装时明确报错。输入文件通过宿主注册获得 asset_id，模型不可任意读取本机路径。
3. 百炼 paraformer-v2 采用异步录音文件 URL 提交、轮询、结果下载；传入可访问的 HTTPS 音频 URL（如宿主上传后获得的 OSS 签名地址）。保留句子 begin_time，超时/失败不写入半份材料。上传仍复用宿主已有能力。
4. `text-embedding-v4` 默认 1024 维，小批量调用、按 index 重排、验证数量/维度/有限值。失败不以虚构向量替代。
5. SQLite 保存纪要、注册资产、来源片段与向量；精确余弦召回适合当前小规模项目，无需额外服务。嵌入模型/维度元数据防止混用；租户/用户/纪要约束覆盖读写。一次材料替换在事务内执行，失败保留旧版本，重复导入不累积副本。
6. `ingest_material(asset_id)` 工具连接抽取→分块→向量→存储；Agent 共用该知识库读取材料、生成纪要/题目、问答。
